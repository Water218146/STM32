# u8g2 移植

Github： https://github.com/olikraus/u8g2

> [!NOTE]
>
> 下文的移植过程基于 硬件 I2C 和 0.91 寸 Oled 进行。



## 准备文件

1. 下载 u8g2 的源文件。

## 编写回调函数

[官方的移植模板](https://github.com/olikraus/u8g2/wiki/Porting-to-new-MCU-platform)

* 在 `mydefine.h` 中引用 `i2c.h` 和 `u8g2.h` ，然后在 `oled_task.c` 中添加以下函数：

```C
uint8_t u8g2_gpio_and_delay_stm32(U8X8_UNUSED u8x8_t *u8x8, U8X8_UNUSED uint8_t msg, U8X8_UNUSED uint8_t arg_int, U8X8_UNUSED void *arg_ptr)
{
	switch(msg){
		
	case U8X8_MSG_GPIO_AND_DELAY_INIT:
	    break;
		
	case U8X8_MSG_DELAY_MILLI:
		HAL_Delay(arg_int);
	    break;
		
	case U8X8_MSG_GPIO_I2C_CLOCK:		
        break;							
		
    case U8X8_MSG_GPIO_I2C_DATA:			
        break;
		
	default:	
		return 0;
	}
	return 1; // command processed successfully.
}

uint8_t u8x8_byte_hw_i2c(u8x8_t *u8x8, uint8_t msg, uint8_t arg_int, void *arg_ptr)
{
  static uint8_t buffer[32];		/* u8g2/u8x8 will never send more than 32 bytes between START_TRANSFER and END_TRANSFER */
  static uint8_t buf_idx;
  uint8_t *data;
 
  switch(msg){
		
    case U8X8_MSG_BYTE_SEND:
      data = (uint8_t *)arg_ptr;      
      while( arg_int > 0 ){
				buffer[buf_idx++] = *data;
				data++;
				arg_int--;
			}      
    break;
			
    case U8X8_MSG_BYTE_INIT:
      /* add your custom code to init i2c subsystem */
    break;
		
    case U8X8_MSG_BYTE_START_TRANSFER:
      buf_idx = 0;
    break;
		
    case U8X8_MSG_BYTE_END_TRANSFER:
      HAL_I2C_Master_Transmit(&hi2c1,u8x8_GetI2CAddress(u8x8), buffer, buf_idx,1000);
    break;
		
    default:
      return 0;
  }
  return 1;
}
```

## 初始化

* 在 `main.c` 中将 Oled 初始化函数 `OLED_Init()`  替换为以下内容：

```C

u8g2_Setup_ssd1306_i2c_128x32_univision_f(&u8g2,U8G2_R0,u8x8_byte_hw_i2c,u8g2_gpio_and_delay_stm32);
u8g2_InitDisplay(&u8g2); 
u8g2_SetPowerSave(&u8g2, 0); 
u8g2_ClearDisplay(&u8g2);

```

* 将 `oled_task` 修改为以下内容：

```C
u8g2_t u8g2;

/* Oled 显示任务 */
void oled_task(void)
{
  u8g2_ClearBuffer(&u8g2);
 
  u8g2_DrawCircle(&u8g2,60,30,20,U8G2_DRAW_ALL);
  
  u8g2_SendBuffer(&u8g2);
}
```

> [!NOTE]
>
> 注意要在 `mydefine.h` 添加  `extern u8g2_t u8g2;` 使之可以跨文件访问，否则无法在 `main.c` 中使用。
