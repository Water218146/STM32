**原始内容：** 基于TB6612FNG双H桥驱动芯片

### 2. 控制逻辑更新

#### 原始TB6612控制逻辑：
```c
// 双引脚方向控制
AIN1=1, AIN2=0  -> 正转
AIN1=0, AIN2=1  -> 反转
AIN1=0, AIN2=0  -> 停止
```

#### 更新后A4950控制逻辑：
```c
// 单引脚方向控制 + 快慢衰减
DIR=0, PWM=速度值     -> 正转（慢衰减）
DIR=1, PWM=100+负值   -> 反转（快衰减）
DIR=0, PWM=0          -> 停止
```

## 技术特点说明

### A4950快慢衰减模式

**慢衰减模式（DIR=0）：**
- 电流衰减慢，转矩波动小
- 适合正转和停止
- 运行更平稳

**快衰减模式（DIR=1）：**
- 电流衰减快，响应速度快
- 适合反转控制
- 制动效果更好

### 电机方向处理

通过reverse参数处理电机安装方向：
```c
int8_t actual_speed = motor->reverse ? -speed : speed;
```

这样可以在软件层面统一电机的正反转定义，无需修改硬件连接。
