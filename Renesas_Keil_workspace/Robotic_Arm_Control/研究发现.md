# 研究发现

## 2026-06-04 工程与原理图阅读

### 工程现状

- `Robotic_Arm_Control` 是 Renesas RA6M5 + Keil MDK + FSP 6.4.0 工程。
- 目标器件为 `R7FA6M5BF3CFP`。
- 当前 FSP 配置主要包含 `IOPORT`，还没有生成 SCI UART、IIC Master 等驱动实例。
- 当前应用入口 `src/hal_entry.c` 只启动 SysTick 和调度器。
- 当前 `APP/scheduler.c` 的任务表含 `NULL` 任务，后续实现前需要先修正调度器任务调用安全性。

### 原理图发现

- 原理图文件为 `机械臂控制板原理图/SCH_Schematic1_2026-06-04.pdf`，共 2 页。
- 第 1 页包含逻辑电源、舵机电源、LDO、RS485、陶晶驰串口屏接口、debug 接口、蜂鸣器和安装孔。
- 第 2 页包含 PCA9685、RA6M5 核心板排针和 6 路舵机接口。
- 控制板硬件已经具备 RS485、PCA9685、陶晶驰串口屏 UART、debug UART 和蜂鸣器接口。

### 协议合同发现

- vision board 工程路径为 `D:\AAAWaterCode\Rtthread_workspace\vision_board_basic`。
- vision board 是 RS485 主站，Robotic_Arm_Control 是 ModbusRTU 从站。
- vision board 当前 RS485 稳定基线为 `57600 8N1`，不要要求改回 `115200`。
- 机械臂控制板从站地址固定为 `1`，ZDT 电机从站地址为 `2`。
- 第一阶段必须支持 Modbus `0x03`、`0x06`、`0x10`。
- CRC 错误帧直接丢弃，不响应；非法地址/非法功能码必须返回 exception。

### 架构约束

- 所有控制来源必须进入统一机械臂状态/命令层。
- Modbus、串口屏和其他任务不得直接抢 PCA9685。
- PCA9685 输出必须由 `servo_target_us` / `servo_current_us` 寄存器模型统一驱动。
- `command_seq` 是命令幂等关键字段，只在变化时执行一次 `command`。

### 待验证事项

- 需要确认 RA6M5 工程中 SCI0/SCI3/SCI5/IIC2 的 FSP 实例配置方案。
- 需要确认 RS485 DE 时序策略和响应发送完成回落策略。
- 需要确认 PCA9685 I2C 频率、地址和初始化参数。
- 需要确认陶晶驰串口屏协议帧格式和动作记录/回放的第一阶段范围。

## 2026-06-07 机械臂关节方向标定

- 用户确认 HMI 硬件为陶晶驰 3.2 寸串口屏，显示分辨率 `320x240`，已导入 GB2312 字库；后续界面必须按 `320x240` 设计，屏幕显示文字优先中文。
- HMI `关节` 页面基础 UI 已完成并烧录验证，页面采用灰色背景，顺序从上到下为 `Grip`、`Roll`、`Pitch`、`Elbow`、`Shldr`、`Base`，对应 PWM5 到 PWM0。
- HMI `关节` 页面 6 个滑条的按下/滑动事件均已验证可实时控制对应机械臂关节；当前仍发送 `A5 01 ch us_l us_h FF FF FF` 的 `ch + us` 协议，不发送角度。
- HMI 页面规划 v0.2 确认为 4 页：`首页`、`手动`、`关节`、`动作`；底部导航固定为 `[首页] [手动] [关节] [动作]`。
- `首页` 设备名为 `机械臂控制终端`，只做状态总览，显示 `状态`、`视觉端`、当前动作、动作步数、错误代码和当前位置，不直接控制机械臂。
- `手动` 页面用于末端 X/Y/Z、腕俯仰、腕旋转、夹爪的实时控制；滑条变化后直接进入 `arm_control`，固件侧后续必须做限幅、速度限制和平滑处理。
- `关节` 页面用于单关节调试、标定、维修，并提供 `[复位]` 与 `[设为复位]`；复位姿态是一组 6 关节目标值，不等于全部舵机 `1500us`。
- `动作` 页面采用完整姿态关键点录制：移动机械臂到目标姿态后点击 `[加一步]`，保存当前 6 关节值、夹爪状态和持续时间；播放完成后自动执行复位姿态并回到 `就绪`。
- 缺陷品分拣链路：vision board 检测缺陷后按传送带速度和机械臂距离同步，随后通过 Modbus 下发播放动作命令，机械臂进入 `忙碌`，执行抓取、放入缺陷盒、自动复位，最后回到 `就绪`，上位机/vision board 轮询到就绪后进入下一轮。
- vision board 不直接控制串口屏再由串口屏转控机械臂；推荐链路为 `vision board -> RS485/ModbusRTU -> RA6M5 arm_control -> PCA9685/舵机`，RA6M5 再同步 HMI 显示。
- 用户确认采用右手基坐标系 v0.2：原点为 J1/Base 腰关节旋转中心，`+Z_base` 从底座竖直向上，`+X_base` 为机械臂中位姿态下末端伸出的水平方向，`+Y_base` 由右手系确定，满足 `X_base x Y_base = Z_base`，等价于 `Y_base = Z_base x X_base`。
- 后续文档中禁止只写“面向 +X”这类模糊描述；必须写成“从原点沿 +X_base 看去”或“从 +X_base 端看回原点”。
- 后续关节角度正负按机械臂坐标系、工具坐标系和右手定则定义，不直接等同于 PWM 脉宽增减。
- 用户实测确认：J1 Base/腰关节对应 PCA9685 PWM0 通道。
- 以从上方俯视底座转盘为观察基准，在 50Hz 舵机 PWM 下，J1 脉宽/高电平时间增大到约 `1600us` 时，腰关节逆时针转。
- J1 脉宽减小时，腰关节顺时针转。
- J1 安全范围已测得 `500-2500us`，以 `1500us` 为 `0deg` 中位时，`500us` 约为 `-90deg`，`2500us` 约为 `+90deg`。
- J1 临时线性映射为 `angle_deg = (pulse_us - 1500) * 0.09`，正方向为从上方俯视底座转盘时逆时针方向。
- 用户实测确认：J2 Shldr/肩关节对应 PCA9685 PWM1 通道。
- J2 是大臂相对底座的俯仰关节；`2327us` 时大臂接近水平向 `+X_base`，定义为约 `0deg`；`1312us` 时大臂接近竖直向 `+Z_base`，定义为约 `+90deg`。
- J2 `500us` 用户确认机械上可接受，保留为复位候选点；HMI 上限可保守设置为 `2300us`。
- J2 脉宽增大时大臂下放，角度减小；脉宽减小时大臂上抬/回收，角度增大。
- J2 `1500-2327us` 区间肩关节扭矩压力较大，动作播放时需要插补、限速，并尽量让肘关节/腕关节配合减小负载。
- 用户实测确认：J3 Elbow/肘关节对应 PCA9685 PWM2 通道。
- J3 显示角定义为小臂相对大臂角，不是小臂相对地面的角度；后续正运动学中，小臂相对地面的角度应由肩关节角和肘关节相对角共同决定。
- 测试基准为大臂保持竖直，近似平行 `+Z_base`；`500us` 时小臂接近 `+X_base` 方向，定义为约 `-90deg`；`1500us` 时小臂接近 `+Z_base` 方向，定义为 `0deg`；`2356us` 时小臂接近 `-X_base` 方向，定义为约 `+90deg`。
- J3 建议 HMI 采用分段显示：`500-1500us` 按 `-90deg` 到 `0deg`，`1500-2356us` 按 `0deg` 到 `+90deg`。
- 用户实测确认：J4 Pitch/腕俯仰对应 PCA9685 PWM3 通道。
- J4 显示角定义为手掌/夹爪相对小臂的俯仰角；测试基准为小臂保持竖直，近似平行 `+Z_base`。
- `1500us` 时手掌/夹爪接近 `+Z_base`，与小臂近似同向，定义为 `0deg`。
- `2443us` 左右时手掌/夹爪接近 `+X_base`，定义为约 `-90deg`。
- J4 脉宽增大时手腕向前下俯，角度变负；脉宽减小时手腕上仰，角度增大。
- J4 建议 HMI 显示公式为 `angle = -(us - 1500) * 90 / 943`；若 HMI 最大值设为 `2500us`，会显示到约 `-95deg`，正式作业可限制到 `2443us`。
- 用户实测确认：J5 Roll/腕旋转对应 PCA9685 PWM4 通道。
- 末端工具坐标系定义：`+X_tool` 为夹爪朝向物体方向，J5/Roll 绕 `+X_tool` 旋转；按右手定则，`+Y_tool` 转向 `+Z_tool` 为 Roll 正方向。
- 观察方向必须写清楚：从 `+X_tool` 端面对夹爪正面，看向 `-X_tool` 方向时，Roll 正方向看起来为逆时针。
- `1457us` 时手掌与 `XY_base` 平面平行，定义为 `0deg`；`2415us` 时接近 `+90deg`，即 `+Y_tool` 转向 `+Z_tool`；`500us` 时接近 `-90deg`，即 `+Z_tool` 转向 `+Y_tool`。
- J5 脉宽增大时 Roll 角度增大；脉宽减小时 Roll 角度减小。
- J5 建议 HMI 采用分段显示：`500-1457us` 按 `-90deg` 到 `0deg`，`1457-2415us` 按 `0deg` 到 `+90deg`；分母分别为 `957` 和 `958`。
- 后续视觉端不要直接下发相机图像角度；PC/vision board 需要先把物体偏转角转换为机器人坐标系或工具坐标系下的 `Roll_target_deg`，再通过 Modbus 下发给 RA6M5。
- 当前临时复位姿态 v0.1 已由用户确认并写入 HMI 关节页前初始化事件：`Base=1500us`、`Shldr=500us`、`Elbow=500us`、`Pitch=2443us`、`Roll=1457us`、`Grip=500us`。当前阶段 HMI 会在关节页前初始化事件中直接下发这 6 路 PWM 到 RA6M5；后续正式固件应由 RA6M5 `arm_control` 保存并执行复位姿态。
- 用户实测确认：J6 Gripper/夹爪对应 PCA9685 PWM5 通道。
- J6 脉宽/高电平时间减小时，夹爪张开；`500us` 左右时夹爪张开最大。
- J6 脉宽/高电平时间增大时，夹爪闭合；`1500us` 左右时夹爪接近完全闭合。
- J6 当前可用 PWM 高电平范围记录为 `500-1500us`。
- 普通舵机夹爪是位置控制，不是力矩控制；夹持大物体时，如果目标闭合量超过物体允许空间，会导致堵转、掉压、发热或内部保护，表现为夹住一会后自动松开。
