## HMI 舵机滑条协议

HMI 硬件与界面约束：

- 串口屏：陶晶驰 3.2 寸屏。
- 显示分辨率：`320x240`。
- 显示文本优先使用中文，已导入 GB2312 字库。
- 后续界面排版必须按 `320x240` 设计，不要按大尺寸屏幕布局。
- 串口屏组件名可以继续使用 `h0`、`n0`、`b0` 这类短英文/数字命名；屏幕上显示给用户看的文字使用中文。

串口屏发送帧格式：

```text
A5 01 ch us_l us_h FF FF FF
```

字段说明：

| 字段 | 含义 |
|---|---|
| `A5` | 帧头 |
| `01` | 舵机 PWM 设置命令 |
| `ch` | PCA9685 通道，当前只用 `0-5` |
| `us_l` | 脉宽低字节 |
| `us_h` | 脉宽高字节 |
| `FF FF FF` | 陶晶驰串口屏帧尾 |

例子：

```text
A5 01 02 A4 08 FF FF FF
```

表示设置通道 `2` 为 `0x08A4 = 2212us`。

## HMI 页面规划 v0.2

页面数量控制为 4 页：

- `首页`：机械臂状态总览，不直接控制机械臂。
- `手动`：实时手动控制机械臂。
- `关节`：单关节调试、标定、维修，包含复位姿态设置。
- `动作`：动作录制、保存、回放。

底部导航固定为：

```text
[首页] [手动] [关节] [动作]
```

所有页面底部导航按钮位置保持一致，当前页面按钮用不同颜色或高亮状态区分。

### 首页

主页设备名为 `机械臂控制终端`，不使用“主控”作为页面或设备名称。
首页只做状态展示，不放实时控制滑条。

320x240 草图：

```text
┌────────────────────────┐
│ 机械臂控制终端          │
│ 状态:就绪  视觉端:在线  │
├────────────────────────┤
│ 当前动作: 00            │
│ 动作步数: 000           │
│ 错误代码: 0             │
│ 当前位置: 复位姿态      │
│                        │
│ [复位]                 │
├────────────────────────┤
│ [首页] [手动] [关节][动作]│
└────────────────────────┘
```

首页控件作用：

| 显示/控件 | 作用 |
|---|---|
| `机械臂控制终端` | 设备名称 |
| `状态` | 显示机械臂当前状态，例如 `就绪`、`忙碌`、`错误`、`复位中`、`回放中` |
| `视觉端` | 显示 vision board 连接状态，例如 `在线`、`离线` |
| `当前动作` | 显示当前执行或待执行的动作编号 |
| `动作步数` | 显示当前动作已执行到第几步 |
| `错误代码` | 显示当前错误码，正常为 `0` |
| `当前位置` | 显示当前是否在 `复位姿态`、`手动位置`、`动作中` 等状态 |
| `[复位]` | 回到预设复位姿态，不等于全部舵机 `1500us` |
| `[首页] [手动] [关节] [动作]` | 固定底部导航标签 |

首页不放 `执行`、`使能`、`急停`：

- `执行` 属于手动页或动作页语义，首页只看状态。
- `使能` 偏底层状态控制，后续可放设置/隐藏命令。
- `急停` 需要完整停机策略和硬件/软件状态配合，未完成前不放在首页，避免语义不清。

```text
┌────────────────────────┐
│ 手动控制          就绪  │
├────────────────────────┤
│ 前后X   000  [──────]   │
│ 左右Y   000  [──────]   │
│ 上下Z   000  [──────]   │
│ 腕俯仰  000  [──────]   │
│ 腕旋转  000  [──────]   │
│ 夹爪    050% [──────]   │
├────────────────────────┤
│ [首页] [手动] [关节][动作]│
└────────────────────────┘
```

手动页控件作用：

| 显示/控件 | 作用 |
|---|---|
| `前后X` | 末端沿基坐标 X 方向实时移动控制 |
| `左右Y` | 末端沿基坐标 Y 方向实时移动控制 |
| `上下Z` | 末端沿基坐标 Z 方向实时移动控制 |
| `腕俯仰` | 末端手腕俯仰姿态实时控制 |
| `腕旋转` | 末端腕部旋转实时控制 |
| `夹爪` | 夹爪开合百分比实时控制 |

手动页第一阶段可以先显示界面，不急于启用 X/Y/Z 联动控制；等关节安全范围和角度映射完成后再启用。

### 关节页

关节页用于单关节调试、标定和复位姿态设置。

```text
┌────────────────────────┐
│ 关节调试          安全  │
├────────────────────────┤
│ 腰    1500  000° [────] │
│ 肩    1500  待测 [────] │
│ 肘    1500  待测 [────] │
│ 腕俯  1500  平行 [────] │
│ 腕旋  1500  待测 [────] │
│ 夹爪  1500  闭合 [────] │
├────────────────────────┤
│ [复位] [设为复位]       │
│ [首页] [手动] [关节][动作]│
└────────────────────────┘
```

关节页控件作用：

| 显示/控件 | 作用 |
|---|---|
| 六个关节滑条 | 单独调整每个舵机，用于标定和维修 |
| `us` 数值 | 显示当前 PWM 高电平，标定时必须可见 |
| 角度/状态 | 显示角度、待测、平行、闭合等状态 |
| `[复位]` | 回到当前保存的复位姿态 |
| `[设为复位]` | 将当前 6 个关节值保存为复位姿态 |

复位姿态是一组固定的 6 关节目标值，后续 `首页复位`、Modbus `home` 命令、动作结束后的自动复位都使用同一组复位姿态。

当前临时复位姿态 v0.1：

```text
Base  / h0 / PWM0 = 1500us
Shldr / h1 / PWM1 = 500us
Elbow / h2 / PWM2 = 500us
Pitch / h3 / PWM3 = 2443us
Roll  / h4 / PWM4 = 1457us
Grip  / h5 / PWM5 = 500us
```

当前阶段 HMI 关节页前初始化事件会直接下发上述 6 路 PWM 到 RA6M5，用于快速验证上电复位姿态。后续正式固件应由 RA6M5 的 `arm_control` 保存并执行复位姿态，HMI 只负责显示和修改。

### 动作页

动作页用于录制和回放完整机械臂动作。动作不按每个关节分别录制，而是记录一组组完整机械臂姿态关键点。

```text
┌────────────────────────┐
│ 动作管理          空闲  │
├────────────────────────┤
│ 编号:00    步数:000     │
│ 速度:100%  间隔:050ms   │
│                        │
│ [录制]    [加一步]      │
│ [播放]    [停止]        │
│ [上一组]  [下一组]      │
│ [清空]    [保存]        │
├────────────────────────┤
│ [首页] [手动] [关节][动作]│
└────────────────────────┘
```

动作录制流程：

1. 在动作页选择 `编号`。
2. 点击 `[录制]`，系统进入录制状态。
3. 切到 `手动` 页或 `关节` 页，把机械臂移动到一个目标姿态。
4. 回到动作页点击 `[加一步]`，保存当前 6 个关节值、夹爪状态和本步持续时间。
5. 重复第 3-4 步，直到完成“抓取、搬运、放下、离开”的全过程。
6. 点击 `[保存]`，动作写入本地动作槽。
7. 点击 `[播放]` 时，机械臂按关键点顺序执行。
8. 播放完成后，系统自动执行 `复位姿态`，然后状态回到 `就绪`。

缺陷品分拣工作链路：

```text
视觉端检测到缺陷
-> 根据传送带速度和机械臂距离等待/同步
-> vision board 通过 Modbus 下发播放动作命令
-> 机械臂状态变为 忙碌
-> 执行抓取动作
-> 放入缺陷盒
-> 自动执行复位姿态
-> 状态回到 就绪
-> 上位机/vision board 轮询到就绪后进入下一轮检测
```

### vision board 与 HMI 数据链路原则

vision board 不直接控制串口屏再由串口屏转控机械臂。推荐链路为：

```text
vision board -> RS485/ModbusRTU -> RA6M5 arm_control -> 舵机/PCA9685
                                              └──────-> HMI 状态显示同步
```

也就是说，vision board 可以下发 `播放动作`、`目标位置`、`模式切换` 等命令给 RA6M5；RA6M5 统一进入 `arm_control` 后执行，并同步刷新 HMI 显示。

## 关节与 PWM 通道规划

PWM 通道按机械臂从下到上排列：

## 机械臂坐标系 v0.2

本工程机械臂坐标系采用右手坐标系。所有旋转关节的正方向均按右手定则定义：右手大拇指指向该关节旋转轴正方向，四指弯曲方向为关节角正方向。

基坐标系 `base`：

- 原点：J1/Base 腰关节旋转中心。
- `+Z_base`：从底座竖直向上。
- `+X_base`：机械臂中位姿态下，末端伸出的水平方向。
- `+Y_base`：由右手系确定，满足 `X_base x Y_base = Z_base`，等价于 `Y_base = Z_base x X_base`。

俯视图：

```text
                 +X_base 机械臂正前方
                         ↑
                         |
        +Y_base  ←--------O--------→  -Y_base
                         |
                         ↓
                    -X_base

O：J1/Base 腰关节旋转中心
+Z_base：从底座竖直向上，也就是从纸面朝外
```

不要在文档中单独使用“面对 +X”描述坐标方向，必须写清楚观察方向。等价观察描述为：

```text
从原点沿 +X_base 正方向看去，画面左侧为 +Y_base。
从 +X_base 端看回原点时，画面右侧为 +Y_base。
```

末端工具坐标系 `tool`：

- `+X_tool`：夹爪朝向物体的方向。
- `+Y_tool`：Roll 为 `0deg` 时夹爪横向参考方向。
- `+Z_tool`：由右手系确定，满足 `X_tool x Y_tool = Z_tool`。
- Wrist Roll/J5 是绕 `+X_tool` 的旋转；`+Y_tool` 转向 `+Z_tool` 为 Roll 正方向。

关节角度正负按机械臂坐标系和各关节旋转轴定义，不直接等同于 PWM 脉宽增减。HMI 当前仍只发送 `ch + us` 给 RA6M5，角度仅作为屏幕调试显示；后续正式运动学应由 RA6M5 的 `arm_control` 统一换算。

| 关节 | 名称 | PWM 通道 | 角度定义/标定点 | us 增大方向 | us 减小方向 | 安全/调试范围 |
|---|---|---:|---|---|---|---|
| J1 | Base/腰关节 | 0 | `500us=-90deg`，`1500us=0deg`，`2500us=+90deg` | 从上方俯视底座为逆时针，角度增大 | 从上方俯视底座为顺时针，角度减小 | `500-2500us` |
| J2 | Shldr/肩关节 | 1 | `2327us≈0deg` 水平向 `+X_base`，`1312us≈+90deg` 竖直向 `+Z_base`，`500us` 为复位候选点 | 大臂下放，角度减小 | 大臂上抬/回收，角度增大 | 机械允许 `500-2327us`，HMI 上限可保守用 `2300us` |
| J3 | Elbow/肘关节 | 2 | 小臂相对大臂角：`500us≈-90deg`，`1500us≈0deg`，`2356us≈+90deg` | 小臂向 `-X_base` 侧转，角度增大 | 小臂向 `+X_base` 侧转，角度减小 | `500-2356us` |
| J4 | Pitch/腕俯仰 | 3 | 手掌/夹爪相对小臂角：`1500us=0deg`，`2443us≈-90deg` | 手腕向前下俯，角度变负 | 手腕上仰，角度增大 | 作业建议 `1500-2443us`，机械可测到约 `2500us` |
| J5 | Roll/腕旋转 | 4 | 绕 `+X_tool`：`500us≈-90deg`，`1457us=0deg`，`2415us≈+90deg` | `+Y_tool` 转向 `+Z_tool`，Roll 增大 | `+Z_tool` 转向 `+Y_tool`，Roll 减小 | `500-2415us` |
| J6 | Grip/夹爪 | 5 | 位置控制，不按关节角参与当前运动学 | 夹爪闭合 | 夹爪张开 | `500-1500us` |

J1 Base 实测记录：

- 观察基准：从上方俯视底座转盘，也就是沿 `+Z_base` 反方向看向原点。
- 正方向：从 `+X_base` 转向 `+Y_base`，俯视图中为逆时针。
- `500us` 对应约 `-90deg`。
- `1500us` 对应约 `0deg`。
- `2500us` 对应约 `+90deg`。
- 临时线性映射：`angle_deg = (pulse_us - 1500) * 0.09`。

J2 Shldr 实测记录：

- J2 对应 PCA9685 `PWM1`，是大臂相对底座的俯仰关节。
- `2327us` 时，大臂接近水平向 `+X_base`，定义为约 `0deg`；HMI 为保守起见可把最大值设为 `2300us`。
- `1312us` 时，大臂接近竖直向 `+Z_base`，定义为约 `+90deg`。
- `500us` 用户确认机械上可接受，保留为复位候选点。
- `us` 增大时大臂下放，角度减小；`us` 减小时大臂上抬/回收，角度增大。
- `1500-2327us` 区间肩关节扭矩压力较大，动作播放时需要插补、限速，并尽量让肘关节/腕关节配合减小负载。
- 当前 HMI 显示公式建议仍以实测 `2327us` 为 `0deg`：`angle = (2327 - us) * 90 / 1015`；滑条最大值用 `2300us` 时显示约 `2deg` 属正常。

J3 Elbow 实测记录：

- J3 对应 PCA9685 `PWM2`，是小臂相对大臂的关节角，不是小臂相对地面的角度。
- 测试基准：大臂保持竖直，近似平行 `+Z_base`。
- `500us` 时小臂接近 `+X_base` 方向，定义为约 `-90deg`。
- `1500us` 时小臂接近 `+Z_base` 方向，与大臂近似同向，定义为 `0deg`。
- `2356us` 时小臂接近 `-X_base` 方向，定义为约 `+90deg`。
- 建议 HMI 采用分段显示：`500-1500us` 按 `-90deg` 到 `0deg`，`1500-2356us` 按 `0deg` 到 `+90deg`。
- 运动学中，小臂相对地面的角度应由肩关节角和肘关节相对角共同决定，不要把 J3 显示角直接当成地面角。

J4 Pitch 实测记录：

- J4 对应 PCA9685 `PWM3`，是手掌/夹爪相对小臂的俯仰角。
- 测试基准：小臂保持竖直，近似平行 `+Z_base`。
- `1500us` 时手掌/夹爪接近 `+Z_base`，与小臂近似同向，定义为 `0deg`。
- `2443us` 左右时手掌/夹爪接近 `+X_base`，定义为约 `-90deg`。
- `us` 增大时手腕向前下俯，角度变负；`us` 减小时手腕上仰，角度增大。
- 建议 HMI 显示公式：`angle = -(us - 1500) * 90 / 943`。
- 若 HMI 最大值设为 `2500us`，会显示到约 `-95deg`；正式作业可把软件上限限制到 `2443us`。

J5 Roll 实测记录：

- J5 对应 PCA9685 `PWM4`，是末端绕 `+X_tool` 的旋转。
- 标准正方向：右手大拇指指向 `+X_tool`，四指弯曲方向为正方向，即 `+Y_tool` 转向 `+Z_tool`。
- 观察方向必须写清楚：从 `+X_tool` 端面对夹爪正面，看向 `-X_tool` 方向时，Roll 正方向看起来为逆时针。
- `1457us` 时手掌与 `XY_base` 平面平行，定义为 `0deg`。
- `2415us` 时接近 `+90deg`，即 `+Y_tool` 转向 `+Z_tool`。
- `500us` 时接近 `-90deg`，即 `+Z_tool` 转向 `+Y_tool`。
- `us` 增大时 Roll 角度增大；`us` 减小时 Roll 角度减小。
- 建议 HMI 采用分段显示：`500-1457us` 按 `-90deg` 到 `0deg`，`1457-2415us` 按 `0deg` 到 `+90deg`。
- HMI 分段公式：`500-1457us` 分母为 `957`；`1457-2415us` 分母为 `958`。
- 后续视觉端不要直接下发相机图像角度；PC/vision board 需要先把物体偏转角转换为机器人坐标系或工具坐标系下的 `Roll_target_deg`，再通过 Modbus 下发给 RA6M5。

J6 Grip 实测记录：

- J6 是末端夹爪，对应 PCA9685 `PWM5`。
- `us` 减小时夹爪张开，`500us` 左右张开最大。
- `us` 增大时夹爪闭合，`1500us` 左右接近完全闭合。
- 当前夹爪可用 PWM 高电平范围记录为 `500-1500us`。
- 普通舵机夹爪是位置控制，不是力矩控制；夹持大物体时不要用过小闭合目标强行加力，否则容易堵转、掉压、发热，甚至夹住一会后自动松开。

## 架构约束

- 所有控制来源，包括 Debug 命令、HMI、后续 Modbus，都必须进入统一 `arm_control` 状态/命令层。
- 各模块不允许直接抢 PCA9685。
- PCA9685 输出必须以 `servo_target_us` / `servo_current_us` 模型为中心。
- 后续将 HMI 从“直接显示 us”逐步升级为“关节名 + 角度/百分比 + 限位 + 当前状态”。
