💡 什么是分辨率？

分辨率 = ARR的值 = 可以调节的档位数量

比如 ARR=100，就是把一个周期分成100份，占空比可以是 0%, 1%, 2%...100%
如果 ARR=10，就只能分成10份，占空比只能是 0%, 10%, 20%...100%

分辨率越高，调节越精细！

🎓 三个概念的区别

1. 频率 = 影响"多快切换一次"（影响平滑度和噪音）
　　→ 低频率：能看到/听到闪烁，电机有噪音
　　→ 高频率：看起来连续，电机安静

2. 占空比 = 影响"平均功率大小"（影响亮度/速度）
　　→ 占空比小：LED暗，电机慢
　　→ 占空比大：LED亮，电机快

3. 分辨率 = 影响"能调多细"（调节精度）
　　→ 分辨率低(ARR=10)：只能粗调 0%, 10%, 20%...
　　→ 分辨率高(ARR=1000)：可以细调 0%, 0.1%, 0.2%...

重点：频率和占空比是独立的！
　　→ 可以是"高频率+低占空比"（快速切换，但开的时间短）
　　→ 也可以是"低频率+高占空比"（慢慢切换，但开的时间长）
