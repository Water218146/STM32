什么是定时器？

🎯 核心概念

定时器（Timer）是单片机中最重要、最常用的外设之一。你可以把它想象成一个超级精准的秒表，可以用来：

  • 精确计时：产生固定时间间隔的中断（如你代码中的1ms定时）
  • PWM输出：控制LED亮度、电机速度、舵机角度
  • 输入捕获：测量脉冲宽度、外部信号频率
  • 编码器接口：读取旋转编码器的位置和速度

PWM 是什么？

🎯 PWM = Pulse Width Modulation（脉冲宽度调制）

PWM是一种用数字信号模拟模拟电压的技术。通过快速开关一个固定电压，控制"开"的时间比例来模拟不同的电压值。

💡 生活中的PWM例子

想象你用手电筒照射墙壁：
• 一直开着 → 墙壁很亮（100%亮度）
• 开1秒，关1秒 → 平均50%亮度
• 开0.1秒，关0.9秒 → 平均10%亮度

如果开关速度够快（如1000次/秒），人眼就看不出闪烁，只看到不同亮度！

📊 PWM 的两个关键参数

参数 含义 影响
频率（Frequency） 每秒钟PWM循环的次数 决定控制的平滑度和噪声
占空比（Duty Cycle） 高电平时间占周期的百分比 决定输出"电压"的大小

🔑 关键要点：PWM频率的影响

PWM频率影响：
1. 控制平滑度：频率太低会有脉动感（LED闪烁、电机抖动）
2. 噪声：20Hz-20kHz会产生可听噪声
3. 响应速度：频率越高，调节响应越快

PWM频率由什么决定：
Fpwm = TIMxCLK / ((PSC+1) × (ARR+1))
• 降低PSC或ARR → 频率升高
• 提高PSC或ARR → 频率降低

占空比如何调整：
通过修改 CCR（捕获比较寄存器）的值
占空比 = CCR / (ARR + 1)

PWM 配置步骤详解
1 使能定时器时钟
↓
2 配置GPIO为复用功能
↓
3 配置定时器时基
↓
4 配置PWM输出通道
↓
5 使能定时器

📝 完整代码示例（基于你的项目）

假设我们要在 PA6 (TIM3_CH1) 上输出PWM：

// ============================================
// 步骤1: 使能时钟
// ============================================
// 使能TIM3定时器时钟（APB1总线）
RCC_APB1PeriphClockCmd(RCC_APB1Periph_TIM3, ENABLE);

// 使能GPIOA时钟（PA6是TIM3_CH1）
RCC_AHBPeriphClockCmd(RCC_AHBPeriph_GPIOA, ENABLE);

// ============================================
// 步骤2: 配置GPIO为复用功能
// ============================================
GPIO_InitTypeDef GPIO_InitStructure;

GPIO_InitStructure.GPIO_Pin = GPIO_Pin_6;              // PA6 = TIM3_CH1
GPIO_InitStructure.GPIO_Mode = GPIO_Mode_AF;              // 复用功能模式
GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;
GPIO_InitStructure.GPIO_OType = GPIO_OType_PP;            // 推挽输出
GPIO_InitStructure.GPIO_PuPd = GPIO_PuPd_UP;               // 上拉
GPIO_Init(GPIOA, &GPIO_InitStructure);

// 将PA6映射到TIM3（AF1）
GPIO_PinAFConfig(GPIOA, GPIO_PinSource6, GPIO_AF_1);

// ============================================
// 步骤3: 配置定时器时基（决定PWM频率）
// ============================================
TIM_TimeBaseInitTypeDef TIM_TimeBaseStructure;

// 目标: 1kHz PWM频率
// 公式: Fpwm = 48MHz / ((PSC+1) * (ARR+1))
// 设: PSC=47, ARR=999
// Fpwm = 48MHz / (48 * 1000) = 1kHz ✓

TIM_TimeBaseStructure.TIM_Period = 999;            // ARR: 自动重装载值
TIM_TimeBaseStructure.TIM_Prescaler = 47;          // PSC: 预分频器
TIM_TimeBaseStructure.TIM_ClockDivision = TIM_CKD_DIV1;
TIM_TimeBaseStructure.TIM_CounterMode = TIM_CounterMode_Up;  // 向上计数

TIM_TimeBaseInit(TIM3, &TIM_TimeBaseStructure);

// ============================================
// 步骤4: 配置PWM输出通道
// ============================================
TIM_OCInitTypeDef TIM_OCInitStructure;

TIM_OCInitStructure.TIM_OCMode = TIM_OCMode_PWM1;           // PWM模式1
TIM_OCInitStructure.TIM_OutputState = TIM_OutputState_Enable; // 使能输出
TIM_OCInitStructure.TIM_Pulse = 500;                       // CCR: 初始占空比50%
TIM_OCInitStructure.TIM_OCPolarity = TIM_OCPolarity_High;     // 高电平有效

// 应用到通道1 (TIM3_CH1)
TIM_OC1Init(TIM3, &TIM_OCInitStructure);
TIM_OC1PreloadConfig(TIM3, TIM_OCPreload_Enable);  // 使能预装载

// ============================================
// 步骤5: 使能定时器
// ============================================
TIM_Cmd(TIM3, ENABLE);  // 启动TIM3，开始输出PWM

// ============================================
// 运行时调整占空比
// ============================================
// 设置新的占空比 (范围: 0 ~ 999)
TIM_SetCompare1(TIM3, 700);  // 70%占空比

PWM模式2 CNT < CCR 无效电平（低）

电机控制与PWM频率

🤔 为什么电机需要高频率PWM？

这是你最关心的问题，让我详细解释：

原因1: 机械惯性 vs 电频率

电机转子有惯性，不能瞬间响应电信号变化。

如果PWM频率太低（比如10Hz）：
• 每0.1秒才变化一次 → 电机转起来一顿一顿的
• 转速不稳定，有明显的脉动感

如果PWM频率够高（比如20kHz）：
• 每0.05ms就变化一次 → 电机根本"感觉"不到开关
• 转子感受到的是"平均"电压，转动非常平滑

原因2: 避免可听噪声

人耳能听到的声音频率范围：20Hz ~ 20kHz

如果PWM频率在这个范围内：
• 电机的线圈会像扬声器一样发出"嗡嗡"声
• 频率越低，声音越大

解决方案：
• 使用高于20kHz的PWM（超声波）
• 人耳听不到，电机运转安静

原因3: 减小电流纹波

PWM驱动电机时，电流是波动的：

低频PWM：
• 电流波动幅度大（纹波大）
• 导致电机发热增加、扭矩脉动
• 影响电机寿命

高频PWM：
• 电流波动幅度小（纹波小）
• 电流更接近直流，电机运转更平稳
• 发热少，效率高

🧮 如何计算电机控制的PWM参数？

需求：驱动直流电机，PWM频率20kHz，占空比可调

Fpwm = 20kHz = 20,000Hz

TIMxCLK = 48MHz (你的项目)

Fpwm = TIMxCLK / ((PSC + 1) × (ARR + 1))

20,000 = 48,000,000 / ((PSC + 1) × (ARR + 1))

方案选择：

  • 方案1（推荐）: PSC=47, ARR=47
    → Fpwm = 48MHz / (48 × 48) ≈ 20.8kHz
    → 分辨率: 48级
  • 方案2: PSC=0, ARR=2399
    → Fpwm = 48MHz / (1 × 2400) = 20kHz
    → 分辨率: 2400级（高精度）
  • 方案3: PSC=23, ARR=99
    → Fpwm = 48MHz / (24 × 100) = 20kHz
    → 分辨率: 100级
// 20kHz PWM配置示例（方案2：高精度）
TIM_TimeBaseStructure.TIM_Period = 2399;       // ARR = 2399
TIM_TimeBaseStructure.TIM_Prescaler = 0;         // PSC = 0,不分频

// Fpwm = 48MHz / (1 × 2400) = 20kHz ✓
// 占空比调节: 0~2399 (2400级精度)
TIM_SetCompare1(TIM3, 1200);  // 50%占空比

⚠️ 注意事项

  • 频率不是越高越好：过高会增加开关损耗，MOS管发热
  • 分辨率 vs 频率：频率越高，ARR越小，占空比调节分辨率越低
  • 电机驱动板：有些驱动板内置PWM频率限制，需查看数据手册
  • 死区时间：H桥驱动需要设置死区，防止上下管直通（需要高级定时器）
